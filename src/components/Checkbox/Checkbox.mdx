# Checkbox

A multi-select input for choosing any number of options from a set, or for a single
confirmation (e.g. accepting a waiver). Use it whenever more than one option can be true
at once.

## Checked states

<Canvas of={CheckboxStories.CheckedStates} />

Three states: unchecked, checked, and indeterminate. Indeterminate is for a parent
checkbox that represents a partially-selected group of children — it always resolves to
fully checked on the first click, it never toggles back to unchecked.

## Sizes

<Canvas of={CheckboxStories.Sizes} />

| Size | Box | Use for |
|---|---|---|
| `mobile` | 20px | Mobile app / narrow viewports |
| `desktop` | 24px | Default — web app, booking flows |
| `kiosk` | 32px | In-venue kiosk, viewed at arm's length |

Regardless of the visual box size, the tappable/clickable hit area is always a minimum of
44×44px, centered on the box.

## States

<Canvas of={CheckboxStories.States} />

Real states are real CSS (`:hover`, `:focus-within`) plus the native `disabled`
attribute — `forceState` exists only so this page can show every state in one static
screenshot, and must never be used in application code.

## Error status

<Canvas of={CheckboxStories.ErrorStatus} />

Error only ever applies when the checkbox is unchecked — matching the Figma component,
which has no Error variant for Checked=Yes or Checked=Indeterminate. Once a box is
checked, any error styling is dropped.

## Tooltip icon and grouping

<Canvas of={CheckboxStories.WithTooltipAndGrouping} />

The optional tooltip icon sits after the label for supplementary help text. Indeterminate
is the standard pattern for a parent checkbox that summarizes a set of child checkboxes
(e.g. "All tee times" above three individual slots).

## Do / Don't

**Do**
- Use for multi-select
- Always include a visible label
- Use indeterminate for parent-child groups

**Don't**
- Use for a single on/off toggle — that's the Toggle component
- Rely on color alone to indicate state
- Nest more than two levels

Layout note: when stacking a group of related checkboxes, keep 8–12px vertical spacing
between items on the containing element — the component itself doesn't enforce this.

---

## Accessibility

Checkbox renders a native `<input type="checkbox">` wrapped in a `<label>`, so clicking
the label text toggles the box and the browser's built-in keyboard behavior (Tab to
focus, Space to toggle) works with no extra wiring. Indeterminate has no JSX attribute on
a native input, so it's set imperatively via a ref effect (`inputRef.current.indeterminate
= true`) and mirrored to assistive tech with `aria-checked="mixed"`. The error state sets
`aria-invalid` on the input.
