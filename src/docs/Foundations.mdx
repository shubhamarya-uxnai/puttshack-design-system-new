## Border Width

Semantic, not numeric — `thin` is the default; escalate only to signal state
or emphasis.

| Token | Value | Use |
|---|---|---|
| `--pk-ref-border-none` | 0px | no stroke |
| `--pk-ref-border-hairline` | 0.5px | ultra-fine dividers |
| `--pk-ref-border-thin` | 1px | **default** — inputs, cards, dividers |
| `--pk-ref-border-medium` | 2px | emphasis — active, selected, focus-adjacent |
| `--pk-ref-border-thick` | 4px | strong emphasis, decorative only |
